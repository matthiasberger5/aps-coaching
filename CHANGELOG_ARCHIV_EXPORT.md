# APS 3.0 – Archiv, Export und Druck

- Analysen werden beim Klick auf **Speichern & analysieren** vollständig mit Spieler, Runde, Schlägen und Analyse im lokalen Archiv gespeichert.
- Eine erneut geladene Runde wird beim nächsten Speichern aktualisiert statt als Dublette angelegt.
- **Neue Runde** behält das Archiv bei.
- Im Profil werden Spielername, Datum, Platz, Score, Strafen und Top-Priorität angezeigt.
- Gespeicherte Runden können im Profil direkt **geladen** und **gelöscht** werden.
- Datenexport enthält das komplette Archiv und kann auf einem anderen Gerät wieder importiert werden.
- Neuer Button **Per Mail exportieren** verwendet auf iPad/iPhone/unterstützten Browsern das Teilen-Menü inklusive JSON-Datei; dort kann Mail gewählt werden.
- Druck startet in einem separaten neutralen Druckdokument, damit die interne Web-App-Adresse nicht mehr als URL des Quelldokuments in der Druckfußzeile erscheint.
- Druckformat ist per CSS auf **A4 Querformat** voreingestellt.
